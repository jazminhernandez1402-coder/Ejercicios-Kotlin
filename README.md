**Alumno:** Hannia Jazmin Hernandez Cruz

Ejercicios de fundamentos de Kotlin y Programacion Orientada a Objetos. Cada ejercicio es un archivo `.kt` independiente que se ejecuta desde la terminal de Visual Studio Code.

## Como ejecutar un ejercicio

```
kotlinc Ejercicio01.kt -include-runtime -d Ejercicio01.jar
java -jar Ejercicio01.jar
```

## Ejercicios incluidos

### Bloque 1. Fundamentos de Kotlin
- `Ejercicio01.kt` - Informacion de un usuario (variables y tipos de datos)
- `Ejercicio02.kt` - Calculadora de almacenamiento (operadores y validaciones)
- `Ejercicio03.kt` - Registro de una compra (entrada de datos y operaciones)

### Bloque 2. Estructuras de control
- `Ejercicio04.kt` - Validacion de acceso (if / else)
- `Ejercicio05.kt` - Menu de configuracion (when)
- `Ejercicio06.kt` - Intentos de inicio de sesion (while)
- `Ejercicio07.kt` - Consumo de bateria (for y acumuladores)

### Bloque 3. Funciones
- `Ejercicio08.kt` - Calculadora mediante funciones
- `Ejercicio09.kt` - Validacion de informacion de registro

### Bloque 4. Programacion Orientada a Objetos

- `Ejercicio11.kt` - Constructores
- `Ejercicio12.kt` - Encapsulamiento

### Bloque 5. Principios de POO
- `Ejercicio13.kt` - Herencia de dispositivos
